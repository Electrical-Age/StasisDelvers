# Stasis Delvers

A Minecraft 26.3 (NeoForge) companion mod for Electrical Age.

**Time stands still** everywhere outside fields kept running
by [electrical](https://github.com/Electrical-Age/ElectricalAge/tree/ports/26.3) power.

A work in progress. Guidebook and explanation will arrive at a later date.

Build: `./gradlew build` (Java 25); the EA jar path is the `eln_jar` property. Tests: `./gradlew runGameTestServer`.
